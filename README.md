# Syvora

Syvora is a unified AI workspace for normal AI chat, project management, team communication, vibe coding, GitHub workflows, AI agents, files, labs, and automations.

## V1

This repository currently contains a front-end V1 prototype built as a static web app so it can run directly on GitHub Pages.

### Included

- Home dashboard
- Normal Chat and Workspace Chat UI
- Projects and Kanban board
- Team chat
- Vibe-coding Build studio
- Code + GitHub workspace
- AI Agents
- Labs
- Files
- Automations
- Settings
- Dark/light theme
- Command palette with Ctrl/Cmd + K
- Responsive layout

## Run locally

Open `index.html` in a browser.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

## Next phase

The front end is intentionally backend-agnostic. The next major phase is connecting real authentication, database storage, AI model APIs, GitHub actions, team accounts, and live app previews/deployments.
